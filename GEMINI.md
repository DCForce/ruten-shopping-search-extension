# GEMINI.md: Project Overview

## Project Overview

This is a browser extension for Chrome and other Chromium-based browsers designed to facilitate searching for products across multiple e-commerce and specialty websites in Taiwan. It allows users to select text on any webpage, right-click, and search for that text on various shopping platforms simultaneously.

The extension is built using standard web technologies:
*   **Core Logic:** JavaScript (ES6+)
*   **UI:** HTML and CSS for the popup interface
*   **Build System:** Webpack 5 is used to bundle JavaScript modules and copy static assets.
*   **Manifest Version:** It uses Manifest V3, the current standard for Chrome extensions.

Key features include:
*   Context menu (right-click) integration for searching.
*   A popup interface to manage settings, view search history, and maintain a simple wishlist.
*   Configuration options to enable/disable specific shopping platforms.
*   Use of `chrome.storage.sync` to synchronize user settings across devices.

## Building and Running

The project uses `npm` to manage dependencies and scripts.

### Key Commands

*   **Install Dependencies:**
    ```bash
    npm install
    ```

*   **Development Build:**
    This command bundles the extension and watches for file changes, automatically rebuilding when a change is detected. The output is placed in the `dist/` directory.
    ```bash
    npm run dev
    ```

*   **Production Build:**
    This command prepares the extension for release. It first updates the version in `src/manifest.json` to match `package.json`, then runs a production build with Webpack.
    ```bash
    npm run build
    ```

*   **Package for Distribution:**
    This command creates a `.zip` archive of the `dist/` directory, ready for uploading to the Chrome Web Store.
    ```bash
    npm run zip
    ```

### Loading the Extension for Development

1.  Run `npm run build` or `npm run dev`.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable "Developer mode".
4.  Click "Load unpacked" and select the `dist` folder generated by the build process.

## Development Conventions

*   **Version Management:** The official version number is managed in `package.json`. Before a production build, the `prepare-manifest` script automatically syncs this version to `src/manifest.json`.
*   **File Structure:**
    *   `src/`: Contains all the source code, including JavaScript, HTML, CSS, and the manifest.
    *   `dist/`: Contains the bundled and built extension files. This directory is the final "unpacked" extension.
    *   `scripts/`: Contains helper scripts, such as the script for zipping the extension.
*   **Testing:** The project currently relies on manual testing. There are no automated test suites or configurations (e.g., Jest, Puppeteer) present.
*   **Dependencies:** Development dependencies are managed in `package.json`. There are no runtime framework dependencies like React or Vue; the project uses vanilla JavaScript.
